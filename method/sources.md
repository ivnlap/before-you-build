# Sources and credits

Before You Build is an original synthesis: the loop, rules, ladder, verdicts and skills are written from scratch for this kit. The ideas behind them come from practitioners and researchers who did the hard work. If you want to go deeper, read the originals.

| Idea in this kit | Where it comes from |
|---|---|
| Treat a startup as a set of hypotheses to test with customers before scaling | Steve Blank, *The Four Steps to the Epiphany* (2005) — Customer Development |
| Build–measure–learn; "leap of faith" assumptions; persevere or pivot | Eric Ries, *The Lean Startup* (2011) |
| Ask about past specifics, not future opinions; compliments are noise; commitment and advancement | Rob Fitzpatrick, *The Mom Test* (2013) |
| Continuous, weekly contact with customers; opportunity mapping before solutions; assumption tests | Teresa Torres, *Continuous Discovery Habits* (2021) |
| Assumption mapping (importance × evidence); a library of experiments; evidence strength | David J. Bland & Alexander Osterwalder, *Testing Business Ideas* (2019) |
| Pretotyping: fake doors, "make sure you're building the right it" | Alberto Savoia, *The Right It* (2019) |
| One-page model of a business; running lean experiments; problem/solution interviews | Ash Maurya, *Running Lean* (2010, 3rd ed. 2022) |
| People "hire" products to make progress; the real competition is the current alternative | Clayton Christensen et al., *Competing Against Luck* (2016); Bob Moesta, *Demand-Side Sales 101* (2020); Tony Ulwick, *Jobs to be Done* (2016) |
| Four product risks: value, usability, feasibility, business viability | Marty Cagan, *Inspired* (2nd ed. 2017) |
| Test the riskiest assumption first, instead of building an MVP | Rik Higham, "The MVP is dead. Long live the RAT" (2016) |
| Removing assumptions multiplies the odds; challenge whether to build at all; label every claim's status | Ivan Zamesin, Next Move Theory canon — [github.com/zamesin/Next-Move-Theory-Canon-and-Skills](https://github.com/zamesin/Next-Move-Theory-Canon-and-Skills) (go there for a far deeper method on segments, jobs and value) |
| 40% "very disappointed" as a product–market-fit signal | Sean Ellis (2009 onward), *Hacking Growth* (2017) |
| Concierge MVP, Wizard of Oz | Widely used lean-startup practice; popularised in the works above |
| Pre-registering success criteria before looking at results | Standard experimental practice in science and online experimentation; see Ron Kohavi, Diane Tang & Ya Xu, *Trustworthy Online Controlled Experiments* (2020) |

No text from these works is reproduced here. Any errors in interpretation are mine.
