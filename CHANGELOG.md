# Changelog

## 0.1.0 — 2026-11-06

First public release.

- Method: the validation loop, nine rules, a six-level evidence ladder, four verdicts, validation debt.
- Seven skills: `byb-start`, `byb-assumptions`, `byb-test-plan`, `byb-interview`, `byb-log`, `byb-decide`, `byb-sprint`.
- Catalog of 14 low-cost tests.
- Templates for every file the skills write.
- Two worked examples (CHANGE and STOP).
- Ten behaviour checks.
- Installation as a Claude Code plugin, as copied skill folders, as Claude.ai uploads, or by copy-paste.
