# Changelog

## 0.1.1 — 2026-11-06

Fixes from a full end-to-end simulation (a founder with four ideas, against a hidden ground truth).

- `byb-start`: a mode for people with several ideas who can't choose — shortlist by testability, parallel one-week kill tests, parked list.
- `byb-start`: an idea that's only *hard to reach* gets a 1-hour access test (one warm intro) before it can be parked; parked ideas carry a revisit trigger and are re-raised when it fires.
- `byb-test-plan`: every branch of a success or kill line must state its own number; honest hour estimates with +50% for coordination-heavy tests, actual hours preferred.
- `byb-log`: records hours actually spent.
- `byb-decide`: after CHANGE the next step is always a pre-registered experiment, including delivering on an obligation; weekly review checks parked ideas and hour overruns.
- Three new behaviour checks (E11–E13).
- README banner.

## 0.1.0 — 2026-11-06

First public release.

- Method: the validation loop, nine rules, a six-level evidence ladder, four verdicts, validation debt.
- Seven skills: `byb-start`, `byb-assumptions`, `byb-test-plan`, `byb-interview`, `byb-log`, `byb-decide`, `byb-sprint`.
- Catalog of 14 low-cost tests.
- Templates for every file the skills write.
- Two worked examples (CHANGE and STOP).
- Ten behaviour checks.
- Installation as a Claude Code plugin, as copied skill folders, as Claude.ai uploads, or by copy-paste.
